# Spendly

Gestionnaire de dépenses quotidiennes en PHP vanilla, personnalisable (catégories, budget mensuel, devise).

## Lancer l'application

```bash
php -S localhost:8000 -t /tmp/workspace/Castelli-hib/Spendly
```

Puis ouvrir `http://localhost:8000/index.php`.

## Fonctionnalités

- Ajout et suppression de dépenses
- Catégories personnalisables
- Définition d'un budget mensuel
- Filtrage par mois et catégorie
- Résumé automatique du mois (dépensé / restant)
